# بنرها و تصاویر سایت + مرکز پشتیبانی هوشمند

تاریخ: ۱۴۰۵/۰۸/۲۵ (2026-11-16) · شاخه: `feat/visual-and-support` · مهاجرت‌ها: `0014_visual_content`، `0015_support_center`

## ۱) بنرها و تصاویر (پنل مدیریت ← «بنرها و تصاویر»)
دسترسی: نقش‌های «مدیر اصلی»، «مدیر» و «مدیر محتوا».

**بنرها** — هر بنر: تصویر رایانه و موبایل (اختیاری)، رنگ زمینه، سایهٔ خوانایی، تا ۸ ردیف متن (برچسب، عنوان، زیرعنوان،
متن) و تا ۳ دکمه با لینک. متن‌ها روی تصویر «نوشته» نمی‌شوند؛ HTML هستند تا خوانا، ترجمه‌پذیر و قابل جست‌وجو بمانند.
- جای نمایش (۱۳ جایگاه): نوار اعلان بالای همهٔ صفحه‌ها، صفحهٔ اصلی (۳ جا)، فروشگاه، صفحهٔ هر محصول، ابزارها (۲ جا)،
  مقاله‌ها، هر مقاله، کتابخانه، مرکز پشتیبانی، حساب کاربری.
- زمان‌بندی (به وقت ایران)، مخاطب (همه / فقط مهمان / فقط کاربر واردشده)، زبان (فارسی / انگلیسی / هر دو)، اولویت.
- چند بنر فعال در یک جا ← ردیف قابل ورق‌زدن با فلش و نقطه (بدون حرکت خودکار).
- لینک دکمه فقط آدرس داخلی (`/shop?type=course`) یا `https://`؛ `javascript:` و `//دامنه` رد می‌شوند.
- کلیک دکمه‌ها شمرده می‌شود (`/go/banner/:id/:n`) و در فهرست بنرها دیده می‌شود.
- پیش‌نمایش زنده (رایانه/موبایل، فارسی/انگلیسی) کنار فرم؛ تا «ذخیره» زده نشود سایت عوض نمی‌شود.

**تصاویر سایت** — ۱۵ جایگاه: لوگو (سرصفحه/پانویس/پنل)، تصویر پیش‌نمایش لینک‌ها (OG)، تصویر بخش آغازین صفحهٔ اصلی
(به‌جای نقشهٔ لوله‌کشی)، سربرگ ۸ صفحه، تصویر کنار فرم ورود، تصویر صفحهٔ خطا، و کاورهای پیش‌فرض دوره/افزونه/مقاله.
هر کدام «بازگشت به پیش‌فرض» دارد. عکس محصولات، مقاله‌ها، تیم و گالری‌ها در فرم خودشان عوض می‌شوند؛ با این‌ها
تقریباً همهٔ تصاویر سایت از پنل قابل تغییرند. **استثنا:** آیکن‌های favicon/برنامهٔ نصب‌شده (هنوز فایل ثابت).

**کتابخانهٔ تصاویر** — بارگذاری چندتایی، توضیح تصویر (alt) فارسی/انگلیسی، شمارش محل استفاده؛ تصویر در حال استفاده حذف
نمی‌شود. همهٔ فایل‌ها از نظر محتوا (magic bytes) بررسی می‌شوند و ابعادشان برای جلوگیری از پرش صفحه ذخیره می‌شود.

## ۲) مرکز پشتیبانی
- صفحهٔ عمومی `/support` در منوی اصلی (برای همه، نه فقط کاربر واردشده): پرسش از «پشتیبان هوشمند»، پرسش‌های رایج
  (از پنل قابل ویرایش)، راه‌های دیگر، هشدار ایمنی بوی گاز (۱۹۴). داده‌ساختار FAQPage برای گوگل.
- تیکت: پیوست تصویر/PDF (۵ مگابایت، فقط صاحب تیکت و پشتیبانی می‌بینند)، نشان «پاسخ جدید» در سرصفحه، بستن تیکت
  توسط کاربر، نظرسنجی 👍/👎، پیشنهاد پاسخ‌های رایج هنگام نوشتن موضوع، انتقال گفتگو با پشتیبان هوشمند به فرم تیکت.
- میز پشتیبانی (پنل): فیلتر «منتظر پاسخ»، نشان خوانده‌نشده، مرتب‌سازی بر اساس فوریت، دسته/فوریت پیشنهادی و «اعمال
  پیشنهاد»، «پیش‌نویس با هوش مصنوعی» (مدیر ویرایش و ارسال می‌کند؛ هوش مصنوعی هیچ‌وقت خودش پاسخ نمی‌فرستد)،
  «پاسخ و بستن»، تیکت‌های قبلی همان کاربر.
- بدون هوش مصنوعی همه‌چیز کار می‌کند: جست‌وجو در پرسش‌های رایج و دسته‌بندی با کلمات کلیدی.

## ۳) روشن کردن هوش مصنوعی روی سرور
```
# /opt/nogiti/.env
FEATURE_AI_SUPPORT=true
AI_API_KEY=<کلید GapGPT — فقط این‌جا>
# اختیاری: AI_MODEL_SUPPORT / AI_MODEL_SUPPORT_TRIAGE / AI_MODEL_SUPPORT_DRAFT
# سقف روزانه (مشترک بین همهٔ قابلیت‌های هوش مصنوعی): AI_DAILY_REQUEST_LIMIT, AI_DAILY_TOKEN_LIMIT
# توقف اضطراری همه: AI_KILL_SWITCH=true
docker compose up -d --build
```
مدل‌ها و نتیجهٔ آزمون: `docs/ai/support-model-evals.md` · اجرای دوباره: `node scripts/ai/eval-support.js`.

## ۴) حریم خصوصی
پیش از ارسال به سرویس هوش مصنوعی، شمارهٔ موبایل، ایمیل، شمارهٔ کارت و کد ملی حذف می‌شوند. پشتیبان هوشمند به حساب،
سفارش و تیکت کاربر دسترسی ندارد. متن اطلاع‌رسانی زیر جعبهٔ پرسش نمایش داده می‌شود. سایت صفحهٔ «حریم خصوصی» جدا
ندارد؛ اگر ساخته شد، همین بند باید به آن اضافه شود.

## ۵) بازگشت (rollback)
`CONFIRM_ROLLBACK=YES node scripts/migrate.js --down 0015` و سپس `--down 0014` (اول پشتیبان بگیرید) (فقط جدول‌ها و ستون‌های جدید حذف می‌شوند)، بعد استقرار نسخهٔ قبلی.
